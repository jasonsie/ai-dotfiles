## How this differs from CLAUDE.md

`CLAUDE.md` and `.claude/rules/` are instructions *for Claude*. They are terse, structured for token efficiency, and use shorthand Claude understands.

These docs are written *for humans* — they explain the **why**, the mental model, and the non-obvious design decisions you'd otherwise have to reverse-engineer from the scripts.
